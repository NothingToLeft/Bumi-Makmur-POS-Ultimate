# Bumi Makmur POS v5.5.0

Rilis ini memperjelas Store Manager sebagai kepala operasional cabang dan menambahkan pengelolaan produk/stok yang aman.

## Sorotan

- Store Manager dapat mengelola seluruh operasional cabangnya, termasuk produk, stok, kategori, pembelian, pemasok, pelanggan, keuangan, QRIS, printer, laporan, dan Kasir.
- Store Manager tidak dapat mengubah identitas usaha global, akun Owner/Manager lain, cabang, restore/reset cloud, atau keamanan utama.
- Panel baru `Kelola Produk & Stok` menyediakan Kosongkan Stok, Arsipkan, Pulihkan, dan Hapus Permanen.
- Hapus permanen hanya tersedia bagi produk stok 0 yang belum pernah dipakai. Produk bersejarah wajib diarsipkan agar laporan aman.
- Kosongkan stok selalu menghasilkan penyesuaian dan audit, bukan menghilangkan riwayat.
- Kategori dapat dikelola Store Manager dengan Firestore Rules yang hanya membuka field kategori.

Tetap kompatibel dengan Web Cloudflare Pages, Windows EXE/MSI, Android APK/AAB, dan Firebase Spark gratis.
