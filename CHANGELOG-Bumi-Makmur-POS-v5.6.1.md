# Bumi Makmur POS v5.6.1

## Quiet Sync UI & Professional Settings Polish

- Mengembalikan halaman Cloud & Backup ke tampilan ringkas seperti versi sebelumnya tanpa menghapus sistem diagnostik v5.6.
- Menghapus pengulangan peringatan cloud pada bar atas, banner global, kartu utama, dan panel status dalam halaman yang sama.
- Banner cloud global tidak lagi ditampilkan ketika pengguna sudah berada di Pengaturan Cloud.
- Kartu utama hanya menampilkan status singkat, waktu sinkron terakhir, dan tombol Sinkronkan Sekarang.
- Detail error, koleksi, kode, dan langkah pemulihan dipindahkan ke panel Diagnostik Sinkronisasi yang dapat dibuka-tutup.
- Status bar desktop memakai kalimat netral: data lokal aktif, cloud perlu diperiksa; tidak lagi mengulang pesan teknis panjang.
- Seluruh fitur v5.6.0 tetap dipertahankan: impor Excel/CSV, PO, riwayat harga, approval, label massal, backup preview, diagnostik, offline queue, dan role Store Manager.
- Tidak ada perubahan struktur Firestore maupun data pengguna.
