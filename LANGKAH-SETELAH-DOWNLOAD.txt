BUMI MAKMUR POS v4.3 — LANGKAH BERIKUTNYA

1. Backup JSON dari aplikasi lama, lalu ekstrak ZIP v4.3.
2. Upload seluruh isi ke repository GitHub yang sama dan commit:
   "Spark FreeSync v4.3 Web PC Android audited release"
3. Actions > Build Bumi Makmur POS v4.3 > Run workflow > test-only.
   Hasil wajib: 59 tests lulus, audit lulus, Vite compile lulus.
4. Actions > Deploy Firebase Spark Rules > Run workflow.
   Workflow hanya deploy Firestore Rules/Indexes; tidak ada Functions/Storage/Blaze.
5. Hubungkan repository ke Cloudflare Pages sesuai CLOUDFLARE-PAGES-SETUP.md,
   lalu jalankan web-and-android setelah URL Pages dan signing secrets siap.

JANGAN:
- upgrade Firebase Blaze atau mengaktifkan billing;
- deploy Cloud Functions/Storage;
- membuat signing key baru bila keystore lama masih tersedia;
- commit service-account JSON, .env, JKS, APK, atau AAB.
