BUMI MAKMUR POS v3.3 — LANGKAH SETELAH DOWNLOAD

1. Backup JSON dari APK lama jika sudah ada data penting.
2. Ekstrak ZIP v3.3.
3. Upload seluruh isi folder ke repository Bumi-Makmur-POS-Ultimate.
4. Commit dengan pesan:
   Add premium e-wallet payments, WhatsApp receipt, and receipt customization v3.3
5. Jika signing key dan GitHub Actions Secrets dari v3.2 sudah ada, JANGAN membuat key baru.
6. Langsung jalankan Build Signed Android Release.
7. Hanya bila belum pernah setup signing: jalankan Generate Android Signing Key sekali, simpan .jks, lalu masukkan empat secret.
8. Tunggu Build Signed Android Release selesai.
9. Download artifact Bumi-Makmur-POS-signed-release.
10. Backup data, hapus APK debug lama hanya jika Android menolak update, lalu instal APK signed v3.3 dan Restore JSON.
11. Setelah login PIN, buka Pengaturan > Keamanan untuk mengaktifkan sidik jari/pengenalan wajah.

JANGAN membuat keystore baru untuk update berikutnya.
