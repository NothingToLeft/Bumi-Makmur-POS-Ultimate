# Bumi Makmur POS v5.7.0

Rilis Smart Barcode Scanner & Camera Control.

## Sorotan

- Pilih kamera depan atau belakang.
- Pilih lensa kamera yang tersedia pada perangkat multi-kamera.
- Flash/torch dan zoom jika didukung kamera.
- Scan barcode dari foto.
- Mode Scan Cepat untuk Kasir.
- Bunyi/getar scan yang dapat diaktifkan atau dimatikan.
- Scanner yang sama dipakai pada Kasir, Tambah Barang, Pembelian/Restok, Penyesuaian Stok, Transfer, dan Product Picker.
- Tes Scanner tersedia dari Pengaturan.
- Scanner USB/Bluetooth tetap didukung.
- Shared barcode + pilihan varian tetap dipertahankan.
- Pemulihan sesi cloud Desktop dari v5.6.2 tetap dipertahankan.

Tidak ada migrasi data dan tidak perlu deploy ulang Firestore Rules untuk rilis ini.
