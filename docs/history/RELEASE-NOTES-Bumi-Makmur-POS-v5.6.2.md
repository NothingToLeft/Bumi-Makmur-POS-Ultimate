# Bumi Makmur POS v5.6.2

Rilis hotfix untuk masalah cloud yang terutama muncul pada aplikasi Desktop Windows, sementara Web tetap berjalan normal.

## Yang diperbaiki

- Persistensi login Firebase Desktop.
- Pemulihan sesi setelah aplikasi Windows ditutup dan dibuka kembali.
- Sinkronisasi inti tidak lagi mati karena satu modul tambahan.
- Diagnostik menampilkan nama koleksi yang bermasalah.
- Catatan error berulang diringkas.
- Status cloud hijau tidak lagi tertimpa error lama.

Tidak ada data yang dihapus dan Firestore Rules tidak berubah.
