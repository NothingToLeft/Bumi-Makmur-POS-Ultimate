# Arsip dokumentasi

Dokumen pada folder ini berasal dari rilis lama. Perintah, nomor versi, hasil tes dan klaim deployment di dalamnya mungkin sudah tidak berlaku. Gunakan [status aktif](../../PROJECT_STATUS.md) dan [indeks dokumentasi](../README.md) untuk pekerjaan baru.

Laporan rilis lama berada di folder ini. Catatan implementasi, struktur dan preview lama berada di `technical/`. Isi dipertahankan untuk audit dan riwayat keputusan; beberapa tes kontrak masih memeriksanya.

Dihapus dari source aktif: `FILE-MANIFEST-SHA256.txt` dan `SOURCE-CHECKSUMS-v6.4.2.sha256` karena tidak lagi cocok dengan source terbaru. `UPLOAD-GITHUB-DESKTOP.md` dihapus karena identik dengan panduan pembaruan lama. Versi aslinya tetap ada pada Git history.
