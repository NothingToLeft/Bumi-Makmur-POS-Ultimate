# Branding Guide — Bumi Makmur POS v6.0.1

## Aset master

`public/branding/bumi-makmur-2-master.png`

Aset master tidak boleh diregangkan, dipotong paksa, diubah proporsinya, atau diganti warna secara otomatis.

## Aset runtime

- `/logo-bm.svg` — wrapper kompatibilitas utama yang dipakai UI lama dan baru.
- `/logo-bm.png` — PNG transparan 1024 px.
- `/icon.svg` — favicon/vector wrapper dengan logo baru.
- `/icons/icon-192.png` — PWA/launcher kecil.
- `/icons/icon-512.png` — PWA/launcher besar.
- `/icons/maskable-512.png` — maskable icon dengan safe-zone.
- `/icons/splash-portrait.png` dan `/icons/splash-landscape.png` — splash Android.
- `/icons/logo-bm-wordmark.png` — wordmark turunan untuk area horizontal.
- `/icons/logo-bm-report.jpg` — aset putih untuk dokumen/report generator yang membutuhkan JPEG.
- `build/icon.ico` — icon Windows multi-resolution.

## Aturan UI

- Gunakan `object-contain` untuk semua gambar brand.
- Jangan gunakan `object-cover` pada logo.
- Beri ruang putih/safe area di launcher icon.
- Logo utama tetap merah, hitam, dan putih; warna UI operasional tidak mengubah warna logo.
