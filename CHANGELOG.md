# Changelog

## 4.3.0 — Spark FreeSync, Web & PC

- Firebase Spark-only: Auth + Firestore; tanpa Functions/Storage/Blaze.
- Cloudflare Pages untuk web dan PC PWA.
- Direct Firestore atomic mutation, idempotency receipt, conflict rebase, audit log.
- Persistent multi-tab cache dan offline queue terenkripsi.
- Perbaikan Firestore rules untuk kasir, pelanggan, stok, piutang, refund, dan delete.
- Nota online Firestore tersanitasi dan identitas toko diperbaiki.
- Batas logo/QRIS aman untuk ukuran dokumen Firestore.
- Service worker, SPA routes, security headers, PWA shortcuts, dan Windows install.
- Workflow Node 24 untuk tests, web, APK, dan AAB.
- Seluruh fitur premium v4.2 dipertahankan.
- Audit akuntansi: HPP neto refund/restock, performa produk neto, pembelian bersih, hutang dan modal pascaretur.
- Audit keamanan: UID sesi cloud wajib cocok, user Manager dibatasi per cabang, nota publik anti-listing, transfer stok dibatasi cabang.
- Scanner USB/Bluetooth keyboard global, Enter-to-add SKU/barcode, barcode varian, dan barcode konversi satuan.
- Test suite diperluas menjadi 59/59 dan `test-only` juga mengompilasi Vite.
